# Mine Guns

Mine Guns is a Minecraft plugin that adds realistic gun mechanics, crafting tables for guns and ammo, and a variety of guns inspired by real-world firearms. This plugin aims to provide an immersive and engaging combat experience within the game, similar to popular battle royale games like Free Fire.

## Install

1. Download the plugin JAR file from the [releases page](https://github.com/yourusername/mine-guns/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your server.

## Use

1. Craft a gun crafting table using the provided recipe.
2. Use the gun crafting table to craft various guns.
3. Craft ammo using the ammo crafter.
4. Equip a gun and shoot to engage in combat.
